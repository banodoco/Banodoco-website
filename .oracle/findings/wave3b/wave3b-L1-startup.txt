## GPU fence result

The source’s GPU loop contains an explicit timeout:

```text
journey/journey.js:1463-1477
```

With `clientWaitSync()` forced to return `TIMEOUT_EXPIRED`:

- 3 seconds: `ready=false`, `active=false`, repeated pending fence calls.
- 9 seconds: still pending because the fence phase began several seconds after page boot.
- 12 seconds: `ready=true`, `active=true`, `scene-static`, before the probe released the fence.

Therefore the GPU fence is bounded by the existing internal timeout. It is not part of the reproduced indefinite-startup result.
