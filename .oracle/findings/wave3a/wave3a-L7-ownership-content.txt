### What “complete contributor index” demonstrably means

The live source explicitly defines the 16 records as **visual slots/opening occupants**, not the complete person ledger (`content/content.js:761-781,793-810`). `PERSON` is explicitly canonical and ledger-backed (`content/contributors.js:13-24,174-184,226-283`). The ownership page renders ledger-derived rows from all `OWNERSHIP` records (`ownership/ownership.js:176-225,259-285`).

Static copy nevertheless calls the 16 slot rows “the complete contributor list” and “authoritative, crawlable version” (`static/index.html:1497-1506`). Therefore, “complete” is unresolved: 16 routable visual positions versus 370 ledger owners. **Finding:** semantic authority/wording conflict, not a join-integrity failure.

Repository copy is also stale: `content/COPY-TABLE.md:36-52,65-66` still describes contributor and link data as placeholders, contradicted by current real records and URLs (`content/content.js:793-810,825-855`). Maintenance risk; not a runtime finding.

Existing no-JS claims apply to the separate static journey, whose content is authored HTML (`static/index.html:28-56`); no explicit ownership-page no-JS ledger promise was found. Treat no-JS ledger availability as a **policy candidate**, not a confirmed contract violation.

**No-finding:** ledger joins, static-row generation, and grant-name joins are internally complete.

**Bounded recommendation:** name the contracts separately: 16 visual slots, 120 portrait pool, 370 ledger persons. Either generate a genuinely complete static index from `PERSON` or relabel the 16-row surface as a slot/opening roster. Add explicit filter labels and make `site.links` the single rendered-link source.

**Remaining browser accessibility probe:** Chromium accessibility snapshot plus VoiceOver/NVDA focus test for both filters before and after typing; record computed name, role, value, announcements, and keyboard reachability. This advances the North Star by making content ownership and accessibility contracts explicit without redesigning the visual system.
