Add a scrim-target wheel/touch regression. **Outcome:** fix modal-scrim ownership.

2. **High | High confidence — lifting one finger cancels a surviving touch scrub.**
   **Fact:** multi-touch `touchstart` is ignored, but every `touchend` calls `endTouchContact()` unconditionally (`journey/scroll.js:915-939`). **Impact:** pinch/second-finger interaction terminates the original finger’s active scrub. **Repro:** start one-finger drag, add/lift a second finger, continue the first; movement stops. Add a multi-touch continuation trace.

Repro: resize 768×1024 → 768×900 without crossing mode.

4. **Medium | Medium confidence — square viewport disagrees with CSS breakpoint semantics.**
