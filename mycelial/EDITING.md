# Editing the deck

- **Copy:** The slide sections and their main narrative copy are in `index.html`, in order from slide 1 through slide 11. Some visuals and labels are generated by the slide script named in the nearby HTML comments.
- **Figures and links:** Slides 10–11's initiative data and links are in `flywheel.js`. Slide 8's illustrative people counter and timing are in `flowers.js`.
- **Slide 1 recipients:** The five `.vc-tile` entries are in the slide 1 markup in `index.html`. Each uses a `<picture>` with an AVIF source and JPEG fallback still, a `data-preview` MP4 for the hover preview, and `data-film` for its Cloudflare Stream overlay film. The tile's `data-title` and `data-artist` supply its title and artist; `data-page` is its external entry link. The visible captions are generated from those attributes. The collage label and its Arca Gidan link are in `.vc-label` in the same markup.
- **Link preview image:** `mycelial-og.jpg` is a 1200×630 JPEG captured from slide 1 at 2× and downsampled, with the footer chrome and motion ring hidden. Start the local server with `PORT=8240 python3 serve.py`, open `http://127.0.0.1:8240/mycelial/index.html` in Playwright at a 1200×630 viewport and device scale factor 2, wait for the opening to settle, inject CSS to hide `.chrome` and `#motion`, and save the screenshot. Downsample it to 1200×630, export JPEG under 300 KB, and inspect it before replacing the image.
- **Checks:** Start the local server with `PORT=8240 python3 serve.py` and run `node tools/deck/check-stress.mjs http://127.0.0.1:8240/mycelial/index.html`. Run `node tools/deck/check-firstload.mjs http://127.0.0.1:8240/mycelial/index.html` to check the first load.
- **Publish:** Follow [PUBLISH.md](../tools/deck/PUBLISH.md) to build a site copy, stamp its asset versions and set the absolute preview image URL for the deployment base.
