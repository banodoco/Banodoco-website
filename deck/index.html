03The gap

What's missing isn't another model, technical tool or hub. It's an accessible place to create with all of it.

Hubs host the models; node graphs wire them together — both built for engineers. Closed tools are easy but limited. Nothing gives artists the power of open source without the nerd hole.

00Why now

And it's only now possible: open video models are finally good enough, and agents can use — and build — tools for you.

Two curves crossed in the last year. Open video models went from curiosities to work artists actually ship, and agents became reliable enough to operate real software. An editor that reaches for the whole ecosystem needs both.

04Astrid

Astrid is that place: an agent-powered creative workspace — a new kind of software that adapts to whoever uses it.

Most software is fixed — shaped once, by one team. Astrid is shaped by everyone who builds on it, and its agents reshape it around each person using it: the deepest technical possibilities, behind an accessible, tactile interface.

07Who it reaches

Builders run Astrid locally and push it to its limits. What they make flows into a polished, hosted Astrid for the far larger audience who'd rather not set anything up — and that audience gives builders a reason to keep building. A competitor would have to copy the community, not just the product.

08A thousand flowers

And Astrid isn't just one app: it's the technical and inspirational foundation for thousands more, each focused on different niches.

With first-class forking, anyone can spin off their own version to focus the community's output on a particular niche: a style, a medium, an audience. Every fork draws from, and adds to, the same shared pool of tools, so each one makes all the others more valuable.

05The sharing model · proposed

One person’s solution becomes someone else’s starting point.

The aim is to make useful discoveries reusable. A creator chooses to publish a tool or workflow; another artist’s agent finds it and brings it into a new project. What travels is a reusable capability, with its maker credited—not every private project.
